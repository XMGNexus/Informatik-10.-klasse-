1 Kapitel 1: Git und GitHub verstehen

1.1 Lernziele

Du kannst:

  • erklären, was Git ist
  • erklären, was GitHub ist
  • den Unterschied zwischen lokal und online beschreiben
  • verstehen, warum Versionen für Schulmaterial nützlich sind

1.2 Was ist Git?

Git ist ein Programm zur Versionsverwaltung.

Das bedeutet:

  • Git merkt sich Änderungen an Dateien
  • Git kann alte Versionen wiederfinden
  • Git hilft, strukturiert an Projekten zu arbeiten

Wenn du also eine Datei aus deinem Kursmaterial änderst, kann Git festhalten, was geändert wurde und wann.

1.3 Was ist GitHub?

GitHub ist eine Online-Plattform für Git-Projekte.

Dort kannst du:

  • deine Dateien online speichern
  • Sicherungen anlegen
  • Projekte mit anderen teilen
  • an mehreren Geräten weiterarbeiten

Kurz gesagt:

  • Git verwaltet Versionen
  • GitHub speichert das Projekt online

1.4 Warum ist das für unseren Kurs sinnvoll?

Für den Informatikkurs am GymHueck ist das praktisch, weil wir:

  • Kursmaterial sichern wollen
  • Materialien nach Themen ordnen können
  • neue Inhalte ergänzen können, ohne alte Stände zu verlieren
  • einen einheitlichen Arbeitsablauf kennenlernen, der auch in echten Software-Projekten verwendet wird

1.5 Wichtige Begriffe

Begriff Bedeutung
Repository Ein Projektordner mit Git-Verwaltung
lokal Auf deinem Computer
remote Auf einem Server, zum Beispiel auf GitHub
Version Ein gespeicherter Bearbeitungsstand
Commit Eine bewusst gespeicherte Änderung

1.6 Merksatz

Git arbeitet lokal.
GitHub speichert zusätzlich online.

1.7 So arbeiten wir in dieser Reihe

Wir nutzen vor allem Visual Studio Code.

Viele Git-Schritte lassen sich dort über die Oberfläche ausführen. Dieselben Schritte kannst du aber auch im Terminal nachvollziehen, zum Beispiel mit:

git add
git commit -m "Nachricht"
git pull
git push

So lernst du sowohl die Bedienung in VS Code als auch die grundlegenden Git-Befehle kennen.
