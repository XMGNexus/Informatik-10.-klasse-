1 Unterrichtsreihe: Einstieg in Git und GitHub

1.1 Worum geht es?

In dieser Kurzreihe lernst du, wie du Git und GitHub nutzen kannst, um dein Kursmaterial und spätere Unterrichtsinhalte des Informatikkurses am GymHueck sicher und geordnet zu speichern.

Git hilft dir dabei, Änderungen an Dateien nachzuverfolgen. GitHub hilft dir dabei, diese Dateien online zu sichern und bei Bedarf mit anderen zu teilen.

1.2 Ziele der Kurzreihe

Am Ende kannst du:

  • erklären, was Git und GitHub jeweils machen
  • ein Repository für Schulmaterial anlegen
  • Dateien in Visual Studio Code mit Git verwalten
  • Änderungen stagen und committen
  • mit pull und push arbeiten
  • eine sinnvolle Ablage für Kursmaterial aufbauen

1.3 Arbeitsweise

Du arbeitest in kleinen Schritten:

  • kurze Erklärungen lesen
  • direkt in Visual Studio Code ausprobieren
  • Git-Begriffe mit der Oberfläche verknüpfen
  • wichtige Schritte auch mit einfachen Terminal-Befehlen nachvollziehen
  • am Ende einen einfachen Arbeitsablauf selbst durchführen

1.4 Wofür wir GitHub nutzen

Unser Ziel ist:

  • neue Versionen nachvollziehen zu können
  • Material für den Informatikkurs geordnet zu sammeln
  • Inhalte bei Bedarf von mehreren Geräten aus zu erreichen
  • Kursmaterial nicht zu verlieren
