## Reflexion Kapitel 1

- Was ist der Unterschied zwischen Git und GitHub?
  - Git verwaltet Versionen und Github speichert das Projekt online
- Warum ist Versionsverwaltung für Schulmaterial sinnvoll?
  - Um Kursmaterial zu sichern
  - Um Materialien nach Themen ordnen zu können
  - Um neue Inhalte ergänzen zu können, ohne alte Stände zu verlieren
  - Um einen einheitlichen Arbeitsablauf kennenzulernen, der auch in echten Software-Projekten verwendet wird
- Was bedeutet lokal, was bedeutet online?
  - Lokal ist örtlich beschränkt
  - Online ist in direkter Verbindung mit der Datenverarbeitungsanlage arbeitend, direkt mit dieser gekoppelt

## Reflexion Kapitel 2

- Was ist ein Repository?
- Ein Repository ist ein Ordner, der mit Git verwaltet wird.
- Welche Ordnerstruktur wäre für den Kurs sinnvoll?
  - Informatikkurs_GymHueck
    ├── Kursmaterial/
    ├── Git_GitHub/
    ├── Projekte/
    └── Bilder/
- Warum sollte ein Projektname klar gewählt werden?
  - Damit man weiß was im Projekt enthalten ist 
- Wozu dient GitHub in diesem Ablauf?
  - Man kann das Projekt in Visual Studio Code öffnen oder mit Git verbinden.

## Reflexion Kapitel 3

- Was bedeutet stage?
  - In VSC gehört Stage zum Schritt, bei dem Änderungen für den nächsten Commit vorgemerkt werden.

- Warum ist add fast dasselbe wie stage?
  - VSC nennt es stage und Git nennt es add wobei beide das selbe bewirken

- Woran erkennt man eine gute Commit-Nachricht?
  - wenn eine kleine Arbeitsphase abgeschlossen ist
  - wenn eine Datei sinnvoll ergänzt wurde
  - wenn ein Kapitel fertig überarbeitet wurde
  - wenn du einen klaren Zwischenstand sichern willst
  
## Reflexion Kapitel 4

- Was macht push?
  - lokale Commits zu GitHub hochladen
- Was macht pull?
  - neue Änderungen von GitHub holen
- Warum ist pull vor dem Arbeiten oft sinnvoll?
  - Um sich erst die neuste version zu holen

## Reflexion Kapitel 5

- Welcher Schritt war einfach?
  - VSC zu öffnen
- Welcher Schritt war noch unsicher?
  - Keine Ahnung
- Wie hilft dir GitHub beim Arbeiten mit Kursmaterial?
  - Kursmaterial speichern
  - spätere Inhalte aus dem Informatikkurs am GymHueck ergänzen
  - deinen Arbeitsstand zuverlässig sichern
